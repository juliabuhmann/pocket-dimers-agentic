Results claim only what is listed here as **primary (pre-registered)**; everything else is labelled *exploratory* in the report.

## 0. Definitions (frozen with the design tag; changes are logged with a reason in RESEARCH_TREE.md)
- **Ligand instance**: non-polymer CCD component in biological assembly 1 (excluding water). Covalently linked multi-CCD ligands are merged where feasible, otherwise flagged. Branched entities and N/O-glycans are excluded from the primary set (flagged). Covalent ligands are flagged and kept. Copies that coincide after the assembly operators (same CCD, centroid <1 Å) are deduplicated.
- **Contact**: heavy-atom distance ≤ vdW_i + vdW_j + 0.5 Å (BioLiP). A residue binds if it has ≥2 atom contacts (BioLiP2; stored as a flag, primary). A ligand is bound if it has ≥2 binding residues. Sensitivity: 4.0 Å plain cutoff.
- **Eligible chains**: protein chains ≥30 aa. Antibody chains are flagged and excluded from the primary analyses.
- **MBS**: ≥2 eligible chains each contribute ≥1 binding residue (Marsh). Strict sensitivity: ≥3 residues on each of ≥2 chains. **SBS** otherwise.
- **Homomer site symmetry**: a site is *on-axis* if one ligand instance contacts symmetry-related chains with near-equivalent residue sets (same UniProt residues contacted on both chains, Jaccard ≥0.5). Otherwise *off-axis* MBS; paired symmetric copies are collapsed to one site via a symmetry-group id.
- **Assembly type** (assembly 1): monomer / homomer / heteromer by UniProt (SIFTS). Marsh's protein-level label is secondary.
- **Additives**: primary = BioLiP2 biological-relevance annotation per ligand (fetched release, sha256 recorded) OR wwPDB "SUBJECT OF INVESTIGATION" flag. Sensitivities: the geometric BioLiP rule without PubMed text, and the PLINDER artifact list. Metals are analysed separately and never pooled with organic ligands.
- **Ligand classes**: Marsh 3-class (cofactor / metal / small molecule) for comparability. Finer classes (scripted from CCD + lists): cofactor, nucleotide-like, heme/porphyrin, sugar, lipid, drug-like, other. **Drug-like (primary)**: CCD maps to ChEMBL (UniChem) as a compound with max phase ≥1 or a pChEMBL activity ≥6 on any target, and is not a cofactor or metabolite. Secondary: Ro5 + QED ≥0.5.
- **Predicted pocket**: pocketcompare describe with atlas settings (--af-mode, merged, ≥10 points). The atlas filter (burrow_score ≥0.03, lining pLDDT ≥70) is applied downstream. In homodimers, pockets symmetric under chain swap are collapsed.
- **Interface pocket**: ≥3 lining residues on each chain (primary); ≥1 on each chain (sensitivity).
- **Dimer-only pocket**: an interface pocket whose residues have overlap coefficient <0.5 with every pocket in the isolated-chain runs (same coordinates) of both chains (sensitivities 0.2, 0.8).
- **Symmetric-copy dedup**: same CCD, centroid <2 Å after assembly operators.
- **Residue→UniProt mapping (PDB)**: per-entry SIFTS XML (`sifts/xml/<id>.xml.gz`, EBI, fetched by script only for entries needed in Part 2 and residue-level analyses). FALLBACK: mmCIF `_struct_ref_seq` segment alignment (rows flagged).
- **Fallbacks (declared)**: if BioLiP2 is unavailable → geometric rule + PLINDER list (flag FALLBACK). If ChEMBL phase/pChEMBL cannot be fetched (ChEMBL REST API for the mapped CCD subset, release recorded; SQLite as alternative) → Ro5 + QED ≥0.5 (flag FALLBACK). Every FALLBACK is reported in the results tables.

## 1. Pre-registered primary hypotheses (BH-corrected within each family; two-sided; α=0.05)
Family A — PDB (Part 1); unit = non-redundant (30% RCSB cluster × ligand CCD), symmetric sites collapsed, oligomers only:
- **H1** (Marsh replication): cofactors are more often at MBS than drug-like ligands are. One representative entry per cluster × CCD (best resolution, ties broken by earliest ID) supplies the MBS label and covariates; "MBS in any entry" is a sensitivity. OR from logistic regression MBS ~ class + spline(heavy atoms) + resolution + method + n_chains + SG flag + release year, cluster-robust SEs).
- **H2** (drug-like occupancy): within the same protein cluster (conditional logistic regression on clusters with both MBS and SBS sites; power gate applied to discordant clusters), drug-like ligand occupancy differs between MBS and SBS. Pocket descriptor (secondary): burrow_score of the burrow pocket at the ligand.
- **H3** (symmetry): in homomers, on-axis MBS sites differ from off-axis MBS sites in drug-like vs cofactor composition. Geometric sensitivity: ligand centroid ≤3 Å from the C2 axis. Expected to be possibly underpowered → descriptive if the power gate fails.
Family B — predicted dimers (Part 2):
- **H4** (recovery): predicted dimer models recover PDB MBS sites better than isolated-chain models of the same coordinates. Estimand: conditional on the predicted interface matching the PDB interface (filter in Q2.1); the unfiltered result and the n removed are also reported. Top-k: n = number of ligand sites of the pair in that PDB entry; isolated-chain top-(n+2) are taken from the pooled pockets of both chains. Homodimers: both chain assignments scored, max taken. Test: paired (site-level), cluster-stratified permutation/bootstrap. Primary contrast: dimer gain at MBS minus dimer gain at SBS (difference-in-differences); the raw MBS gain is also reported.
- **H5** (disease): ClinVar P/LP missense variants (primary outcome) are enriched at dimer-only pocket residues vs interface residues outside any pocket (single primary contrast). Residue categories are mutually exclusive in the order dimer-only pocket > single-chain pocket > interface > other surface. Residue-level logistic GLMM with a protein random intercept, adjusted for relative SASA (burial), pLDDT and conservation (if a conservation score is cheaply available, else noted). AlphaMissense (aa_substitutions file, UniProt numbering; mean pathogenicity per residue) and the other contrasts are secondary.
Power gate: before each test, count the units per stratum. Inference needs ≥30 clusters per stratum, otherwise the result is reported descriptively (logged).

## 2. Part 1 — PDB census
Local PDB (261,139 mmCIF, snapshot 2026-10-09), X-ray ≤3.0 Å / EM ≤3.5 Å, assembly 1 ≤60 chains. Exclusion ledger at every step.
Analyses: MBS fraction by assembly type × class, before/after additive filtering. Compare to Q-BioLiP (28.8%) and PLINDER (25%) published fractions; cross-check against the PLINDER annotation_table only if anonymous GCS access works (HTTPS returned 403 in r2); otherwise dropped and logged. Tests H1–H3. Druggability descriptors (burrow pocket at ligand: volume, burrow_score, hydrophobic lining fraction; fpocket druggability if it installs — absence is logged, not silently skipped), conditional on ligand class and size. Sensitivities: strict MBS, 4 Å contacts, PLINDER additives, author=software assembly agreement only, leave-out top-10 clusters / top-10 ligands.

## 3. Part 2 — predicted dimers (AFDB, human primary)
Scope: results hold for **confident** interfaces only (pre-filtered ipSAE ≥0.6, pDockQ2 ≥0.23); stratify by ipSAE tertile and by whether a PDB complex of the pair exists.
- **Q2.1 Recovery (H4).** Benchmark = Part 1 sites (additive-filtered) on human UniProt pairs with a dimer model. Only sites whose PDB chain pair corresponds to the predicted pair and whose interface overlaps the predicted interface (interface-residue Jaccard ≥0.3, reported) are kept. Feasibility gate first: count non-redundant MBS sites per homo/hetero (<100 hetero → hetero descriptive only). PDB residues are mapped to UniProt via per-residue SIFTS; sites with <90% residue-name identity are dropped. Primary metric: **DCC ≤4 Å** (ligand centroid transformed by CA superposition of the mapped residues onto the model vs pocket centre) within top-(n+2) pockets by burrow_score. Secondary: residue recall, overlap coefficient, F1, reported with pocket size. Null: size-matched random surface patches in the same model (seeds 0–2). Comparisons: dimer vs isolated chain at equal top-k (primary, H4); vs AFDB monomer atlas (secondary); SBS sites as positive control. Stratify by PDB release vs AF training cutoff, counting a pair as "post-cutoff" only if it had no complex entry before the cutoff. Calibration: burrow on the LIGYSIS human set if time allows (should), compared to published fpocket+PRANK 60.4% and P2Rank ~52–54%.
- **Q2.2 Dimer vs monomer pockets.** Interface vs single-chain pocket properties in the same models. Expected interface-pocket rate vs the interface fraction of surface area. Dimer-only pocket counts homo vs hetero. Novelty vs the monomer atlas: max cosine excluding the protein itself and its ≥30% identity paralogs; size-matched backgrounds; positive control of PDB interface sites. Exploratory, because pocketcompare is weak at PPI pockets.
- **Q2.3 Ligandability of dimer-only pockets.** (a) List human proteins whose only confident (pLDDT ≥70, burrow_score ≥0.03) pocket of drug-like size appears in the dimer; annotate with ChEMBL target status / Open Targets tractability if fetchable. (b) kNN ligand-class transfer from PDB-ligand pocket fingerprints: *exploratory*, validated with a Pfam-clan split (pdb_chain_pfam.tsv from SIFTS; ECOD too heavy), an abstain option and AUPRC vs prevalence, and tested separately on MBS-mapped and SBS-mapped pockets. Dropped if validation AUPRC ≤ prevalence + 0.05.
- **Q2.4 (H5) Disease variants** at dimer-only pocket residues (ClinVar via UniProt variation API or ClinVar VCF; AlphaMissense human file — both fetched by script).
- **Q2.5 Co-folding.** 40–60 jobs, preferring post-cutoff multi-chain cases plus deep-dive cases. Each is folded twice: partner present vs absent (and/or ligand ± partner). Engine = whichever docs/COFOLDING.md shows produces finite output in ≤10 min/job; Boltz-2 if AF3 is unstable on Turing. Metrics: ligand-in-interface-pocket (DCC ≤4 Å to the pocket), ligand RMSD vs PDB when it exists, pocket formation. Memorisation caveat stated.
- *Could*: human vs mouse ortholog conservation of interface pockets (conditional on the ortholog dimer existing); paralog-heterodimer retention; ASD allosteric overlap.

## 4. Deep dives (pre-registered selection rule)
Candidates = all primary + exploratory comparisons, with the total count reported. Ranked by |effect size| with a CI excluding the null, then by biological interpretability (named proteins with structures). Top 3 each get structures, literature context and a co-folding check. Selection rationale is logged before the deep-dive work starts.

## 5. Statistics & reproducibility
Seeds [0, 1, 2] (config); seed 0 is primary and the others are reported as robustness checks. Effect sizes with 95% bootstrap CIs over clusters (1,000 resamples). BH within families A and B. Exploratory results are labelled as such. Config files hashed (sha256) and the hash is written into every results file. DESIGN.md is frozen by git tag `design-v3-frozen` after round 2; deviations are logged. Exclusion ledgers in every pipeline. Known-answer sentinels (HIV-1 protease inhibitor = on-axis homodimer MBS; lysozyme = SBS; additive GOL/SO4 dropped; synthetic planted pocket; shuffled-label negative control) run at the start of each pipeline and abort it on failure. Headline numbers are independently re-derived by a separate agent from raw tables. The final report tags claims VERIFIED/UNVERIFIED. PI spot-checks ≥10 random sites per class.

## 6. Compute plan & order
Census (≤24 workers) ∥ dimer describe (≤16 workers; cache and reuse) → SIFTS mapping → ligand-site describe on a non-redundant stratified subset (≤60k sites) → FAISS on GPU / matrix products → recovery → variants. Co-folding (GPUs 1–3) prepared in parallel and launched once the engine is chosen (deadline ~21:00 for the engine choice). Atlas snapshot copied off scratch (scripts/snapshot_atlas.sh). Storage target <100 GB.

## 7. Cut order if time slips
Q2.4 cross-species → kNN transfer → LIGYSIS calibration → PLINDER cross-check → co-folding size (down to 20 jobs).

## 8. Known risks
Confident-only dimer set; AF training overlap; pocket splitting differences (match by residues); pocketcompare weak on PPI pockets; AF3 NaNs on Turing GPUs; scratch purge (atlas copied).
