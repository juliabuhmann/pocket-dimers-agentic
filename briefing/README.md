# Briefing

- `briefing.md` → `briefing.pdf`: research briefing for a broad scientific audience.
- `make_figures.py`: regenerates `figures/*.png` from the tables in `results/` and `reviews/` (environment: `envs/venv_briefing.txt`). Figure 1's process counts (commits, wall-clock hours) come from the original study workspace's git history and are frozen in `figure_inputs/fig1_counts.json`. The figures were regenerated byte-identically in this repository.
- `build_pdf.sh`: renders the PDF with pandoc + tectonic (environment: `envs/conda_pdf.txt`; set `PDF_ENV` to its prefix). The first run downloads LaTeX packages.
- `FIGURE_SOURCES.md`: data sources and caption notes for each figure.
